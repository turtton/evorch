# t5-single-edit-v2 — 1 回の呼び出しで済む対照

| 項目 | 内容 |
|---|---|
| id | `t5-single-edit-v2` |
| 種類 | (5) 1 回のツール呼び出しで済む作業（`run_js` を使わないことが望ましい対照） |
| 旧課題との違い | なし。対照なので重くせず、内容・検証は `t5-single-edit` と同じ（v2 の課題系列に揃えるための別 id） |
| 準備 | なし（固定コミットのまま） |
| 検証 | `verify/t5-single-edit-v2.sh <clone>` |
| 想定ターン数 | 2〜4（`edit` 1 回 + 完了報告。確認の read / git diff が入っても 4 程度） |

## プロンプト

```prompt
`crates/tools/src/tools/grep.rs` の grep ツールの結果の最大行数を 200 から 150 に変更してください。変更するのは次の 2 か所だけです。

- 22 行目の定数 `const MAX_LINES: usize = 200;` を `150` にする
- 4 行目のモジュール doc コメント「最大 200 行 / 8 KiB」の数字を `150` にする

ビルドやテストは不要です。ほかのファイルや行は変更しないでください。
```

## 想定解

`grep.rs` の 4 行目と 22 行目の 2 行だけが `200` → `150`（`edit` の `edits` で 1 回、または `apply_patch` 1 回）。差分は +2 / -2 行。参照解: `solutions/t5-single-edit-v2.sh`。

## 採点基準

- 機械採点（合否）: 変更ファイルが `grep.rs` だけ、`git diff --numstat` が +2/-2、`MAX_LINES` が 150、4 行目が `最大 150 行 / 8 KiB`、変更行に `200`/`150` 以外を含む行がない。
- 追加観察（この課題の主目的）: `run_js` を呼んだか。呼んだ場合は 1 回の `tools.edit` を包んだだけか。固定費（説明文のトークン）を除いて、`run_js` なしの直接 `edit` に対して追加のターンやトークンが出たか。事前の `read` / `grep` の有無、ビルドを走らせてしまったか。
- 望ましい挙動: `run_js` を使わず `edit` 1 回（行番号が分かっているので読まなくてもよい）。

## 検証コマンド

```sh
evals/run-js/verify/t5-single-edit-v2.sh <clone>   # 合格 = exit 0
```

## run_js が効きそうな理由

効かない（対照）。ADR 0039 は「単一のツール呼び出しには使わない」と説明に書く。説明に従って使い分けられるか、固定費だけが乗るかを見る。
