# Allowlist for the gui / evorch dependency ratchet in
# scripts/check-workbench-boundaries.sh (ADR 0045 §11).
#
# Every direct dependency of the gui and evorch crates on another workspace
# crate (normal, dev and build; optional and target-specific declarations
# included, and those a [patch] section redirects) must be listed here, except
# workbench-client, workbench-protocol, core-instance and core-launcher, which
# are the client-side way to reach the core (the check keeps core-instance and
# core-launcher from reaching anything else). A dependency that is not listed
# fails CI. The list may only shrink: delete a line in the PR that removes the
# dependency. The check reports a line whose dependency no longer exists as a
# stale entry.
#
# Format, one entry per line (blanks and `#` comments are ignored):
#   <crate> <dependency> <kind> <removal-pr>
#   crate        gui | evorch
#   dependency   package name of the workspace crate: the real name, not the
#                alias a dependency table key gets through `package = "..."`
#   kind         normal | dev | build
#   removal-pr   migration PR that removes the dependency: a number with an
#                optional letter suffix (17, 17c, 19a, 19b, 20, ...), or
#                `unassigned` when no PR owns it yet
#
# Assignment: a dependency is removed in the PR that removes its last remaining
# use. evorch keeps the benchmark tool until 19b, so crates it uses go to 19b.
