# What a feature PR may change (ADR 0045, single-core migration plan). Read by
# scripts/check-central-files.sh together with central-files.txt: a changed file
# must not be central and must match one pattern of the PR's scope.
#
# One scope per line: `<scope> <item>...`. An item is a bash glob (`*` also
# matches `/`) or `area:<name>`, which stands for the files a PR owns for the
# namespace <name>: its protocol module, adapter, host service, GUI feature,
# samples and golden file, each as `<area>.rs` or inside `<area>/`, and the tests
# whose file name starts with `<area>`.
#
# memory, improvement and evaluation are owned by PR 13 first; 14 and 17c take
# them over only after 13 is merged, so no two scopes are open on them at once.
# `docs/*` is every scope's. PR 16a-1 measures the renderer outside the
# workspace (no new crate, manifest or CI group yet; ADR 0045 re-review R2), so
# its scope is documents and measurement data only. The renderer crates enter
# through a small integration PR once the measurement is accepted. The later
# waves add their scopes in the integration PR that precedes them.
